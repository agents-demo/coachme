# Racket-Angle Proxy (Wrist / Forearm Orientation)

**Status:** not started — stub
**Phase:** C12 — Table-tennis specific
**Effort:** M
**Depends on:** pose landmarks + ball direction + contact timing

## Goal

Estimate wrist/forearm orientation at contact as a coaching hint. This is a
proxy, not the racket face — the label "approximate" must always be shown.

## Acceptance

- Proxy shown with an explicit caveat that it is not a measured racket angle.
- Never presented as ground truth.
