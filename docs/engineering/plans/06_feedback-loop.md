# Feedback Loop (Thumbs / Corrections)

**Status:** not started — stub
**Phase:** 0.3 — Foundations
**Effort:** S
**Depends on:** nothing

## Goal

Capture per-issue thumbs-up/down and "this is wrong" corrections; store them;
use them to guide prompt improvements.

## Acceptance

- Feedback persists per report issue.
- A `tools/` view lists disagreements grouped by prompt version.
- Prompt changes reference the feedback that motivated them.
