# Engineering

| Doc | One-line summary | Type | Use when |
|---|---|---|---|
| [Investigator plan](plans/investigator.md) | Full design and implementation spec: architecture, tools, evidence ledger, budgets, tests and rollout. | **Next development plan** | You are building or reviewing Investigator |
| [Benchmark plan](plans/benchmark.md) | Shared benchmark for Standard vs Investigator: clips, coach labels, blind A/B, metrics and release gates. | **Validation plan** | You need to decide whether Investigator is ready |
| [Priorities](plans/priorities.md) | Product and feature priorities, gaps and sequencing across the app. | **Prioritization plan** | You are choosing what to build next |
| [Architecture](reference/architecture.md) | Layers, dependency direction, package map and runtime structure. | **General reference** | You are changing structure or adding a module |
| [Analysis ideas](research/analysis-ideas.md) | Research backlog of coach-driven measurement and computer-vision ideas. | **Research backlog** | You are looking for analysis improvements, not committed work |

**Start here:** implementers use the Investigator plan; product decisions use `Priorities`.
